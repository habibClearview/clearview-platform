# The approved site design, as inputs to the build

`HANDOFF.md` is Claude Design's build brief, unedited.

`data/` holds the content model lifted out of the approved prototype, one file
per block, exactly as designed. These are the strings the site renders: the
five services, the ten diagnostic questions, the proof entries, the canvas, the
readiness tiers, the ICC blocks, the IDC phases, the TraLiMM models, the
resources, the videos. They are kept here rather than retyped into components,
so a difference between the approved design and the built site is a diff rather
than an argument.

The prototype itself is a 2MB single file and is not committed. It references
its six images by asset id, which only Claude Design's runtime resolves, so it
would not render here anyway.

## Two things carried over deliberately unresolved

**The Chapter 01 market statistics.** The prototype opens with four count-ups —
28% aid fall, 11 donor countries, $65m average blended finance deal, and a
LinkedIn readership figure. Unlike STATS, these are claims about the world
rather than about Habib's work, and no source came with them. They are not to
be published until sourced or cut.

**The word "Decision".** The prototype's diagnostic says "Decision 2"; the rest
of the system says "Decision Point 2", which was a deliberate decision after
the screen called the same thing four different names. The built site uses
Decision Point.
